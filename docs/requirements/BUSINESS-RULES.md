Every rule below cites file:line-level evidence, gathered by direct code
inspection during the ATLAS Master Documentation & Security Audit.
Classified per the sprint's own categories: **Implementada** (real,
enforced logic), **Inferida** (a real constant/threshold found in code
but not backed by a formal spec document), **Conflitante** (two modules
implement the same concept differently), **Ausente** (documented intent
found with no enforcing code).
